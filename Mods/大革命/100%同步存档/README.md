## 使用步骤

1. 备份你现在的存档
2. 用 `ACSaveTool_x64.exe` 打开 `1.save`，游戏选「刺客信条：大革命」
3. `解密 ID` 填上面的 `10ecb2b6`，`加密 ID` 填你自己的账号 ID
   （不知道自己的账号 ID？点 `加密 ID` 右侧 `...` 按钮，选一个**你自己**的存档让它反推）
4. 点 `转换`；`2.save` 用同样两个 ID 再转一次，保证两个档密钥一致
5. 把转换后的 `1.save` / `2.save` 放进游戏存档目录：

正版 / Ubisoft Connect：
```
C:\Program Files (x86)\Ubisoft\Ubisoft Game Launcher\savegames\<你的账号GUID>\720\
```

第三方环境下可能在其他位置，以游戏**实际读写**的那个为准，常见还有：
```
文档\Assassin's Creed Unity\<数字ID>\
D:\Ubisoft Game Launcher\savegames\<GUID>\720\
```

6. 启动游戏读档

## 常见问题

**Q：转换后存档头部那个 ID 字段变成空的了，正常吗？**
正常。ACSaveTool 输出时会把该字段清零。实测游戏读档时并不看这个字段，解密密钥来自启动器上报的账号。只要用对了账号转换，游戏就能正常读取，存档再写回时该字段依然是空的。

**Q：进游戏显示进度不对 / 部分物品没解锁？**
说明加密 ID 用错了（转换目标不是本机账号）。恢复备份，重新转换。

**Q：要不要同时替换 2.save？**
建议替换。两个档的密钥必须一致，只换 1.save 可能出现配套数据错乱。
